# SAHARA — Landing Page

A responsive, single-page landing site concept for SAHARA – The Social Welfare Society of the IIT Madras BS Degree community.

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual system and layouts
- `script.js` — mobile navigation and gallery lightbox interactions
- `assets/sahara-logo.jpg` — logo supplied with the assignment

## Before official publication
1. Replace the illustrative gallery photographs with SAHARA-approved event images.
2. Confirm current team members and roles; the displayed names/roles are selected from the public reference website and may be historical.
3. Replace generic social profile links with verified SAHARA accounts.
4. Replace the generic Google Forms URL with the current official join form.
5. Review the final copy and branding with the society.

## Deploy
The folder can be uploaded to GitHub Pages, Netlify, or Vercel as a static site. For GitHub Pages, create a public repository, upload all files, and enable Pages from the `main` branch root.
